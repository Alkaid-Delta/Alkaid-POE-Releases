# PoE Alkaid — 公開版下載

目前版本 **0.4.50**：台服 Steam POE 1 **3.30.0** 核心相容、藥劑群組與詞綴目錄更新。

章節核心的地圖全開、自動喝水、角色連接與雷達跟隨已有實測回報。藥劑群組、巫影密會新標記與勞工新資料仍保留待實測狀態；入圖機制預測暫停。請先不要使用勞工消耗通貨，詳細範圍見發行說明。

前往 [最新發行版](https://github.com/Alkaid-Delta/Alkaid-POE-Releases/releases/latest)，下載 `PoE-Alkaid-0.4.50-friends-win-x64.zip`，完整解壓縮後執行 `啟動PoEAlkaid.cmd` 或帶圖示的 `PoePersonal.exe`。

需要 Windows 64 位元與 .NET Framework 4.8。國際服與其他客戶端尚待核對。
