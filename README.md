# PoE Alkaid — 朋友版下載

本倉庫提供 PoE Alkaid 朋友版的發行檔與更新說明。

前往 [Releases](https://github.com/Alkaid-Delta/Alkaid-POE-Releases/releases)，下載 `PoE-Alkaid-版本號-friends-win-x64.zip`，完整解壓縮後執行 `啟動PoEAlkaid.cmd`。

需要 Windows 64 位元與 .NET Framework 4.8。適用遊戲版本、已知限制與操作方式請參閱各版說明及 ZIP 內的使用說明。

0.4.39起支援程式內檢查、下載與更新；舊版需先手動安裝一次。GitHub 自動產生的 Source code 壓縮包不是可執行程式。
