# PoE Alkaid — 公開版下載

目前版本 **0.4.46**：台服 Steam POE 1 **3.30.0** 核心相容更新。

已實測正常：地圖全開、自動喝水與怪物／機制標記。入圖機制預測暫停；勞工與製作資料仍待 3.30 校對，請先不要使用勞工消耗通貨。詳細限制請閱讀發行說明。

前往 [最新發行版](https://github.com/Alkaid-Delta/Alkaid-POE-Releases/releases/latest)，下載 `PoE-Alkaid-0.4.46-friends-win-x64.zip`，完整解壓縮後執行 `啟動PoEAlkaid.cmd`。`friends` 是既有通道的相容檔名，對外名稱為公開版。

需要 Windows 64 位元與 .NET Framework 4.8；國際服與其他客戶端尚待驗證。

0.4.39 起支援程式內檢查、簽章驗證、下載與更新。更早版本須先手動安裝一次。GitHub 自動產生的 Source code 壓縮包不是可執行程式。
