# PoE Alkaid 公開版

目前版本 **0.4.86**。下載 ZIP 後解壓，開啟「啟動PoEAlkaid.cmd」。既有使用者可從「設定 > 更新檢查」升級。

[最新版本與下載](https://github.com/Alkaid-Delta/Alkaid-POE-Releases/releases/latest)

- 吞噬天地祭壇選擇後顯示「吞噬天地祭壇(已選取)」。
- 石化琥珀、山銅、維里西姆完成後顯示「礦名(完成)」，與緋紅鍛鐵、鉍一致。清怪或防守期間維持礦名。
- 持續觀察到同一座神殿從可用變為已使用時，顯示「神殿(已使用)」。
- 靠近惡魔召喚者時顯示「超越」。
