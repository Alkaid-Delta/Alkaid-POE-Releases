# PoE Alkaid 公開版

目前版本 **0.4.85**。下載 ZIP 後解壓，開啟「啟動PoEAlkaid.cmd」。既有使用者可從「設定 > 更新檢查」升級。

[最新版本與下載](https://github.com/Alkaid-Delta/Alkaid-POE-Releases/releases/latest)

- 自動藥劑在進圖「恩典」期間暫停，保護解除後依原設定恢復。
- 改善密集怪群與戰亂期間的怪物標記更新。
- 卡爾葛可選擇提前顯示候選位置，靠近後確認礦種或遺失貨物。支援已核對遊戲版本與地圖配置，預設關閉。
- 緋紅鍛鐵及鉍礦床完成後顯示完成，隱藏礦物副體的白點。穿越門可顯示已開門與完成，灼烙總督祭壇選擇後顯示已選取。
